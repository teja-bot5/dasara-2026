# Dasara 2026 · Vijayawada

A website for Dasara 2026 in Vijayawada, built to provide festival information, events, pooja registration and chanda contributions in one place.

## Live Website

🌐 https://dasara-2026.onrender.com

## Features

- Festival information and events
- Daily Pooja registration
- Kumkum Pooja registration
- Chanda contributions through UPI
- Google Sheets integration for registrations
- Responsive design for mobile and desktop

## Tech Stack

- HTML
- CSS
- JavaScript
- Node.js
- Express
- SQLite
- Google Sheets API
