# Dasara 2026 · Vijayawada

Website for the Dasara Utsav: events, pooja registration and chanda (offerings).

## Structure
- `frontend/` : static site (HTML, CSS, vanilla JS)
- `backend/`  : Node + Express API (added in Phase 3)
- `data/`     : content + database files (git-ignored, contains personal data)

## Run the frontend now (Phase 1)
Open `frontend/index.html` in a browser, or from this folder run:

    cd frontend && python3 -m http.server 8000

then visit http://localhost:8000
